# Phase 4B Extension Archive

This folder serves as the permanent archive for the Phase 4B Targeted Knowledge Poisoning Extension experiment for the IEEE manuscript.

## Experiment Configuration
- **Targeted Samples:** 500
- **Attack Category:** Knowledge Poisoning (diverse fallback heuristics)
- **FAISS Index:** `faiss_index_targeted_extension.index` (106,963 chunks)
- **Validation:** 20/20 samples successfully retrieved the poisoned chunk.

## Final Metrics
- **Targeted ASR**: 2.40%
- **Targeted Top-1 RCR**: 55.00%
- **Targeted Top-3 RCR**: 99.80%

## Memory Utilization
- **Peak RAM**: ~12.77 GB
- **Peak Swap**: ~19.47 GB

This archive contains all tabular data, CSVs, LaTeX exports, plots, and statistical analyses generated during the evaluation run.
